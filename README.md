# Spotify Playlist Enricher

A personal project for enriching music playlist metadata and performing music collection analysis.

## Project

This project collects and analyzes metadata associated with music playlists and uses publicly available music metadata services for additional information such as:

* Genre
* Mood
* BPM / tempo
* Key
* Musical metadata
* Artist and release information

## Data Sources

This project uses multiple independent music metadata services for enrichment.

[GetSongBPM](https://getsongbpm.com/)
